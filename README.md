A lightweight XSLT editor with real-time compilation

### Features
- XSLT 1.0 / 2.0 / 3.0 ([Saxon-HE](https://github.com/Saxonica/Saxon-HE))
- Smart autocompletion
- Plugin support
- Real-time compilation
- Light & dark themes
